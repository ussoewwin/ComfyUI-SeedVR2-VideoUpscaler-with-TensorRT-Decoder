## 中文说明

**标签：** `v1.5.2`
**范围：** 修复 TensorRT VAE 解码器黑块（空白 tile）回归问题、引擎选择重构、安装器版本固定清理
**日期：** 2026-09-08

本版本修复了 TensorRT VAE 解码器中的**黑块（空白 tile）回归问题**：在某些配置下，解码帧的左上区域会渲染为纯黑块。根因是引擎选择错误——解码器只查找硬编码的引擎帧大小列表，导致磁盘上实际存在的引擎（25f / 29f / 41f / 61f 等）从未被选中，解码要么静默回退到 PyTorch VAE，要么在强制使用不匹配的引擎时产生损坏输出。

### 变更摘要

| 领域 | 组件 | 实现细节 |
|---|---|---|
| **引擎选择重构** | `src/core/trt_decoder.py` | `pick_engine_frames()` 现在扫描实际存在的引擎文件（`tensorrt_backend/artifacts`、`models/tensorrt/seedvr2`），取代硬编码的 `(video_frames, 29, 21, 5)` 列表。 |
| **不再静默回退** | `src/core/trt_decoder.py` | `resolve_engine_frames()` 返回磁盘上最大的引擎。短于最小引擎的片段会先填充、单次解码后再裁剪——只要存在任何引擎，就**绝不静默回退**到 PyTorch VAE。 |
| **按批次选择引擎** | `src/core/infer.py` | `_trt_decode_batch()` 根据实际批次长度选择引擎（短批次自动填充 + 裁剪），取代全局固定列表。 |
| **可选调试钩子** | `src/core/trt_decoder.py` `src/core/infer.py` | 新增 `SEEDVR2_TRT_DEBUG=1` 诊断：逐 tile 输出统计（min/max/std）并标记黑 tile、输入 latent 统计（NaN/Inf、零能量行列、左上 tile 能量），以及通过 `SEEDVR2_TRT_DEBUG_DIR` 保存张量。默认关闭，不影响正常运行。 |
| **安装器版本固定清理** | `install.py` | 删除所有硬编码版本固定（`tensorrt-rtx`、`onnx`、`onnxscript`、`polygraphy`），改为安装最新版本。 |
| **平台适配的 Triton** | `install.py` | Linux 安装 `triton`，Windows 安装 `triton-windows`（无版本固定，匹配已安装的 torch）。 |
| **不触碰 PyTorch** | `requirements.txt` | 从 `requirements.txt` 移除 `torch` / `torchvision`——尊重 ComfyUI 自带的 PyTorch，安装器绝不触碰。 |

### 安装

在节点目录运行 `install.py`（或 `Install TensorRT SeedVR2.bat`）。注意力后端（SageAttention / FlashAttention）仍为可选，缺失时使用 PyTorch SDPA。TensorRT VAE 解码器引擎可从 Hugging Face 引擎包（Blackwell / RTX 50 系列）下载，或用 `SeedVR2 Build TensorRT VAE Engines` 节点本地构建（解码器要求 `tile_size: 256`）。
