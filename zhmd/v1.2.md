**标签：** `v1.2`  
**提交：** `c56373b`（含功能提交 `a14db91`）  
**日期：** 2026-07-28

本版本通过构建时 `comfy.ops.mixed_precision_ops`，为 SeedVR2 DiT 权重（`format == nvfp4` + `weight_scale` / `weight_scale_2`）增加**原生 NVFP4 加载**；并加入 **Windows / inductor 修复**，使 FP16 VAE 的 `torch.compile` 不再因 cp932 解码或 `aten.bmm` 的 fallback+decomp 断言而失败。

**指南（完整说明）：** https://github.com/ussoewwin/ComfyUI-SeedVR2_VideoUpscaler/blob/main/md/SEEDVR2_NVFP4_AND_TORCH_COMPILE_GUIDE.md

---

## 1. 摘要

| 主题 | 状态 |
|------|------|
| **NVFP4 问题** | 加载后替换 Linear 永远走不到 `comfy.ops` 的 `_load_quantized_module` → 打包的 NVFP4 被展开 → 显存节省失效（与 INT8 同类） |
| **NVFP4 修复** | 构建 NaDiT 时注入 `mixed_precision_ops` → QuantizedTensor 路径；跳过 DiT autocast；必要时将 Linear 激活转为 FP16/BF16 |
| **torch.compile 问题** | 日文 Windows 上 VAE compile：`'cp932' codec can't decode…` → 回退未编译；随后 `AssertionError: both a fallback and a decomp for same op: aten.bmm.default` |
| **torch.compile 修复** | UTF-8 jinja 加载 + OEM/cp932 `errors="replace"` + 当 op 已在 decomp 表中时 `make_fallback(..., override_decomp=True)`；在自定义节点 import 时应用 |
| **范围** | **DiT** NVFP4（及既有 INT8 路径）。**VAE** 仍为 FP16（仅 compile 修复） |

---

## 2. NVFP4 加载路径（构建时 ops）

1. **检测：** `checkpoint_is_nvfp4()`（`*.comfy_quant` → `format == nvfp4`）。
2. **构建：** meta 上 `create_object(..., operations=get_nvfp4_mixed_precision_ops(...))`。
3. **加载前准备：** 复用 INT8 辅助（`prepare_hswq_state_dict_for_comfy_ops`、`patch_ops_factory_device`）。
4. 若 GPU 无原生 NVFP4 计算，将 `"nvfp4"` 放入 `disabled`，存储保持打包，matmul 时反量化。
5. 包装 `ops.Linear.forward`，在 `quantize_nvfp4` 会拒绝 float32 时把激活转为 FP16/BF16。
6. 在 DiT 放大阶段，对原生 NVFP4 **跳过 `torch.autocast`**，避免 LayerNorm/RMSNorm 把 float32 喂进 NVFP4 Linear。

与 GGUF 分支独立；与 INT8 的构建时 ops 家族共享。

## 3. torch.compile / inductor 修复

| 失败 | 对策 |
|------|------|
| 区域设置 **cp932** 下 Jinja / 模板 `open()` | 将 `load_template` 补丁为 `encoding="utf-8"`；重新绑定已有 `functools.partial` 钩子 |
| `SUBPROCESS_DECODE_ARGS = ('oem',)` 严格解码 | 使用 `(encoding, "replace")` / `("oem", "replace")` |
| `both a fallback and a decomp for same op: aten.bmm.default` | 包装 `make_fallback` → 当 op 已在 decomp 表中时 `override_decomp=True`；重新绑定 `graph.make_fallback` |
| 补丁时机 | 在 `__init__.py` import 时调用 `_fix_inductor_windows_encoding()`（并保留 model_configuration 调用） |

**不会**为这些错误禁用 compile，也不会为此重映射 `max-autotune`。

## 5. 使用说明

- 需要提供 `comfy.ops.mixed_precision_ops` 的 ComfyUI 构建，以及按 GPU 所需的 NVFP4 / kitchen 支持。
- 将 DiT 包放到 `models/SEEDVR2/`（或本节点模型目录）；在节点 UI 中选择 NVFP4 safetensors。
- VAE 仍为 FP16；本修复落地后可照常启用 VAE `torch.compile`。
- **v1.1** 的 INT8 原生路径仍然可用。
