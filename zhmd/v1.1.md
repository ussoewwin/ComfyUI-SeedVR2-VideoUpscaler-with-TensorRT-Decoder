**标签：** `v1.1`  
**提交：** `3515c33`  
**日期：** 2026-07-28

本版本通过构建时注入 `comfy.ops.mixed_precision_ops`，为 SeedVR2 DiT 权重（`int8_tensorwise` + `comfy_quant` / `weight_scale`）增加**原生 INT8 加载**，使 INT8 权重包在 `load_state_dict` 过程中保持量化，而不是展开为完整 FP16。

**指南（完整说明）：** https://github.com/ussoewwin/ComfyUI-SeedVR2-VideoUpscaler-with-TensorRT-Decoder/blob/main/zhmd/SEEDVR2_INT8_NATIVE_OPS_GUIDE.md

---

## 1. 摘要

| 主题 | 状态 |
|------|------|
| **问题** | 加载后替换 Linear（GGUF 风格）永远走不到 `comfy.ops` 的 `_load_quantized_module` → 完整 INT8→FP16 展开 → 显存节省失效 |
| **修复** | 构建 NaDiT 时注入 `mixed_precision_ops` → 走 QuantizedTensor 加载路径 |
| **范围** | **仅 DiT**（3B / 7B）。VAE 仍为 FP16 |
| **判定** | `comfy_quant` JSON 中 `format == int8_tensorwise`（不用文件名启发式） |

---

## 2. 为何对本 INT8 格式，加载后替换是错误的

GGUF 风格加载器在权重已上模块**之后**才替换 Linear。使用 `comfy_quant` 的 SeedVR2 INT8 包需要 ComfyUI 的 **state_dict 加载钩子**（`_load_from_state_dict` → `_load_quantized_module`）。若用普通 `torch.nn.Linear` 构建再事后替换，会跳过该路径。

---

## 3. 加载路径（构建时 ops）

1. **检测** INT8：`checkpoint_is_hswq_int8`（`*.comfy_quant` → `int8_tensorwise`）。
2. **构建** meta 上的 DiT：`create_object(..., operations=get_hswq_mixed_precision_ops(fp16))`（YAML 不变；仅此路径注入 ops）。
3. **加载前准备：** 将 `comfy_quant` 张量移到 CPU；把 `factory_kwargs["device"]` 打到真实设备，避免 QuantizedTensor 卡在 meta。
4. **`load_state_dict`** — 带标记的层变为 QuantizedTensor；其余层仍为普通 Parameter。
5. 与 GGUF 分支独立。

---

## 4. 本标签涉及的代码面

| 路径 | 作用 |
|------|------|
| `src/optimization/int8_native_ops.py` | 检测 / `mixed_precision_ops` / comfy_quant→CPU / factory 设备补丁 |
| `src/common/config.py` | `create_object(..., **extra_kwargs)` 以支持 `operations=` |
| `src/core/model_loader.py` | 检测 → 注入 ops → 准备 → 加载 |
| `src/utils/model_registry.py` | 注册 `seedvr2_7b_int8_convrot` / sharp；`resolve_dit_config_folder` 使用 registry 的 `size` |
| `src/models/dit_3b/**`、`dit_7b/**` | 在 MLP、embedding、patch、attention、window 块中传播 `operations` / `ops.Linear` |
| `seedvr2_int8_bench.py` | FP16 与原生 INT8 DiT 对比（同一加载路径） |

---

## 5. 使用说明

- 需要提供 `comfy.ops.mixed_precision_ops` 的 ComfyUI 构建。
- 将 DiT 包放到 `models/SEEDVR2/`（或本节点模型目录）；在节点 UI 中选择 INT8 safetensors，或把路径传给 bench 脚本。
- 示例权重：`seedvr2_7b_int8_convrot.safetensors`、`seedvr2_7b_sharp_int8_convrot.safetensors`。
- VAE 示例仍为 FP16（例如 `ema_vae_fp16.safetensors`）。

Bench（在本自定义节点根目录）：

```bash
python seedvr2_int8_bench.py \
  --fp16 seedvr2_ema_7b_fp16.safetensors \
  --int8 seedvr2_7b_int8_convrot.safetensors \
  --vae ema_vae_fp16.safetensors
```
