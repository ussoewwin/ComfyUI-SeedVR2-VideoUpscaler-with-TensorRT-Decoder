**标签：** `v1.5.3`
**范围：** TensorRT VAE 编码器启用未成功（左上角分块伪影）
**日期：** 2026-09-09

本版本记录了 TensorRT VAE **编码器** 启用的一次未成功尝试；视频编码因此继续使用标准 FP16 VAE，同时 TensorRT **解码器** 完整可用。编码器的左上角分块伪影 —— 分块边缘感受野不足与填充污染叠加 —— 在 256px 或 512px 分块尺寸下均无法消除，因此该编码器并未随版本发布。

---

## 1. 变更摘要

| 区域 | 涉及文件 | 实现细节 |
|---|---|---|
| **TensorRT VAE 编码器（启用未成功）** | `src/interfaces/__init__.py`, `__init__.py` | `SeedVR2LoadTensorRTVAEModel`（编码 + 解码 TRT）在启用尝试期间注册，因左上角分块伪影无法解决而被再次移除。`SeedVR2LoadTensorRTVAEDecoder`（仅解码 TRT）与 `SeedVR2BuildTensorRTVAE` 仍可用。 |
| **FP16 VAE 编码路径保持不变** | `src/core/infer.py` | 对现有 FP16 编码路径进行了评估（尝试过批量一次性变体并已回退），最终保持原样：逐帧循环仍是编码实现。 |

---

## 2. 深入剖析

### 2.1 左上角分块伪影（TensorRT 编码器）

TensorRT VAE 编码器将填充后的帧切分为 256px/512px 的 tile，并用余弦羽化与 DC 偏移校正拼接 latent。每个 tile 的左上角位于 tile 边缘 —— 编码器感受野在此被截断 —— 且紧邻 replicate 填充区域，其非自然（边缘重复）内容污染编码器的中间特征，产生可见的左上角模糊/噪点带。

已尝试的缓解措施及其测得的左上角 latent 标准差（中心 ≈ 1.0）：

| 措施 | 结果 |
|---|---|
| 无外围填充 | 1.70 |
| `reflect` 填充 | 黑块（5D 不支持 / 已回退） |
| 零填充 | 1.34 |
| Replicate 填充（四边） | 1.27 |
| 重叠 96 / 128 / 192px | 无变化 |
| 边缘丢弃 | 无变化 |
| 余弦羽化 | 无变化 |
| DC 偏移校正 | 无变化 |
| 半 tile 外围填充 | 已尝试 |

该伪影无法降至 ~1.27–1.36 以下，因此 TensorRT 编码器未随版本发布。缓解代码（半 tile 填充、`set_input_shape` 后的 `synchronize`）保留在 `src/core/trt_encoder.py` 中供后续工作使用。

### 2.2 FP16 编码路径评估（批量变体已尝试并回退）

作为编码器评估的一部分，测试了 `vae_encode` 的批量一次性变体（将整个 `[1,C,T,H,W]` 片段一次性交给 `vae.encode`）。该变体**在 FP16 VAE 上同样复现了左上角模糊**，因此已被回退 —— 逐帧循环仍是 FP16 编码实现，与先前版本保持一致。
