**标签：** `v1.4`  
**范围：** 在 `MODEL_REGISTRY` 中登记 3B INT8 / NVFP4  
**日期：** 2026-07-31

本版本在 `MODEL_REGISTRY` 中按与 7B 相同的方式登记 **3B** HSWQ INT8 ConvRot 与 NVFP4 DiT 权重包。量化显存仍为内容检测（`*.comfy_quant` + 构建时 `comfy.ops.mixed_precision_ops`）。文件名已含 `3b`，配置目录选择保持历史规则 `"7b" in dit_model`（否则 `configs_3b`）。

## 1. 摘要

| 主题 | 状态 |
|------|------|
| **3B INT8 ConvRot 权重包** | 登记为 `seedvr2_3b_int8_convrot.safetensors`（`precision="int8_tensorwise_convrot"`） |
| **3B NVFP4 权重包** | 登记为 `seedvr2_3b_nvfp4.safetensors`（`precision="nvfp4"`） |
| **原生显存路径** | 不变：基于内容的 `*.comfy_quant` + 构建时 `comfy.ops.mixed_precision_ops`（与 7B 相同） |
| **配置目录选择** | 与 v1.3 相同（`"7b" in dit_model` → `configs_7b`，否则 `configs_3b`） |

示例模型文件：

- `models/SEEDVR2/seedvr2_3b_int8_convrot.safetensors`
- `models/SEEDVR2/seedvr2_3b_nvfp4.safetensors`

## 2. 变更内容

### 2.1 在 `MODEL_REGISTRY` 中登记 3B INT8 / NVFP4

`src/utils/model_registry.py`：

```python
    # HSWQ INT8 / NVFP4 (native VRAM path; same as 7B)
    "seedvr2_3b_int8_convrot.safetensors": ModelInfo(size="3B", precision="int8_tensorwise_convrot"),
    "seedvr2_3b_nvfp4.safetensors": ModelInfo(size="3B", precision="nvfp4"),
```

仅登记 registry **不会**实现量化；打包显存仍依赖内容检测 + 构建时 ops。
