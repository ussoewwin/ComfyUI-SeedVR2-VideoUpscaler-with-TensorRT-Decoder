## 2. 深度架构改进与代码细节

### 2.1 全自动零干预依赖安装（`install.py`）
此前，若仅通过 ComfyUI Manager 或直接运行 `python install.py`，核心依赖（如 `diffusers`、`peft`、`rotary_embedding_torch`、`onnxscript`、`polygraphy` 等）不会被自动安装，因为 `install.py` 仅验证了预设 Wheel 和 TensorRT 引擎，必须手动运行 `Install TensorRT SeedVR2.bat`。

在 `v1.5.1` 中，`install.py` 内部集成了自动依赖解析与安装：
```python
def install_requirements():
    req_file = os.path.join(REPO_ROOT, "requirements.txt")
    if not os.path.isfile(req_file):
        return True
    cmd = [sys.executable, "-s", "-m", "pip", "install", "-r", req_file, "--no-warn-script-location"]
    result = subprocess.run(cmd)
    return result.returncode == 0
```
该机制确保节点在无论是虚拟环境（venv）还是独立便携式 Python（`python_embeded`）中首次加载或执行安装时，均能自动补齐完整依赖。

### 2.2 注意力机制架构统一与 SDPA 标准化（及 FA/SA 手动安装规范）
此前在安装脚本中硬编码外部 FlashAttention 2 与 SageAttention 2 wheel 下载地址，极易因用户 Python 版本（3.11、3.12、3.13）、CUDA 驱动及平台 ABI 差异导致 pip 安装报错或符号缺失（参见 Issue [#1](https://github.com/ussoewwin/ComfyUI-SeedVR2-VideoUpscaler-with-TensorRT-Decoder/issues/1)）。

- **废除 Wheel 自动下载机制：**
  - 从 `install.py` 中彻底移除 `FLASH_ATTN_WHEELS`、`SAGE_ATTN_WHEELS` 及 `install_wheels()`。
  - 从 `scripts/install.ps1` 中彻底移除 `Install-CachedWheel` 与自动下载逻辑。
- **FA / SA 手动安装规范：**
  - FlashAttention 与 SageAttention 为可选加速组件。若用户希望使用 FA 或 SA，必须针对自身的 Python 与 CUDA 环境自行编译或下载兼容的 Wheel 手动安装至 ComfyUI 环境中。
- **无缝回退至 PyTorch 原生 SDPA：**
  - 当环境中未安装专用的加速 Kernel 时，系统统一使用 PyTorch 原生 SDPA（`torch.nn.functional.scaled_dot_product_attention`）。
  - 用户在 `SeedVR2LoadDiTModel` 节点中将 `attention_mode` 设为 `sdpa` 即可稳定运行，无需编译外部库。
  - 验证脚本 `scripts/verify_install.py` 将其显示为 `not available (using SDPA)` 并正常通过。

### 2.3 全链路多候选 FFmpeg PATH 自动解析
SeedVR2 视频处理管线依赖 `ffmpeg` 执行视频帧拆解与编码导出。在标准的 Windows ComfyUI 便携版中，FFmpeg 通常放置在 ComfyUI 便携根目录或随 `imageio_ffmpeg` 打包在 site-packages 中，但并不存在于系统全局 `PATH` 环境变量中，导致视频导出时崩溃。

`_ensure_ffmpeg_path()` 已深度集成至 `__init__.py`、`install.py`、`scripts/verify_install.py` 和 `inference_cli.py`：
1. **现有 PATH 检查：** 调用 `shutil.which("ffmpeg")`。
2. **多级目录候选扫描：** 主动向上扫描 ComfyUI 根目录、上级便携式目录及常见的 `ffmpeg/bin`、`bin` 文件夹。
3. **`imageio_ffmpeg` 动态自动兜底：** 若仍未找到，自动获取 `imageio_ffmpeg.get_ffmpeg_exe()` 所在目录并将其前置加入 `os.environ["PATH"]`。

该逻辑在 `__init__.py` 加载时即刻生效，使 ComfyUI 进程无需用户手动配置 Windows 环境变量即可正常调用 FFmpeg。

### 2.4 TensorRT VAE 解码器空间分块尺寸约束（`tile_size: 256`）
TensorRT VAE 解码器底层（`src/core/trt_decoder.py`）严格针对 256x256 空间切片进行设计。若在构建解码器引擎时将 `tile_size` 设为 `512`，会导致编译出的引擎与推理时分块重建的 Tensor 形状不一致，从而抛出 Shape Mismatch 错误。

中英文文档已更新明确指引：
- **`tile_size: 256`**：**构建 VAE 解码器引擎（`kind: decoder` 或 `kind: both`）时必须设为 256**。
- **`tile_size: 512`**：仅供 VAE 编码器（`kind: encoder`）使用。
